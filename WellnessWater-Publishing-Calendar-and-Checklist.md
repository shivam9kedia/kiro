# Wellness Water Company — Publishing Checklist & 6-Month Content Calendar
## Rollout Plan for the 25 Pillar Articles

*Companion to `WellnessWater-25-Pillar-Blog-Content.md` and `WellnessWater-Citations-and-Infographic-Briefs.md`. This is the operational plan: what to do before launch, the repeatable checklist for every post, the week-by-week calendar, the internal-linking map, and the KPIs to track.*

## PART 1 — ONE-TIME PRE-LAUNCH SETUP (do this first)

Complete these once before publishing Article #1. They make every later post rank faster.

- [ ] **Confirm SEO plugin** (Yoast or Rank Math) is installed and configured; enable XML sitemap.
- [ ] **Create a `/blog/` hub** (or use the existing one) that links to all clusters.
- [ ] **Set up 5 cluster category pages** (Contaminants, Hard Water, Buying Guides, Health & Family, Technology & Trust) so articles roll up to a topic hub.
- [ ] **Map internal links to money pages:** Whole-House Filtration, Water Softeners, Reverse Osmosis/Drinking, combo system, and the free-water-test/contact page.
- [ ] **Resolve legacy/duplicate URLs** found in the sitemap (the `-old`, `duplicate-`, and test pages) — 301-redirect or noindex them so they don't dilute authority.
- [ ] **Add Organization + LocalBusiness schema** site-wide, and an author/reviewer profile for **Dr. Ronald Sidney Stuart, M.D.** (links from health-article review stamps).
- [ ] **Create the "free water test" lead form** and a zip-code lookup if possible, to embed in high-intent posts.
- [ ] **Set up tracking:** Google Search Console, GA4 goals for water-test form submits and calls, and rank tracking for the 25 focus keywords.
- [ ] **Prepare the brand-claim proof points** (NASA-grade tech, lifetime warranty, certifications, physician on team) so they can be cited consistently.

## PART 2 — THE PER-ARTICLE PUBLISHING CHECKLIST (repeat for all 25)

Use this exact checklist every time you publish one of the pillars.

### A. Content & On-Page
- [ ] Paste the body; confirm a single **H1** distinct from the SEO Title.
- [ ] Enter **SEO Title**, **Slug**, **Meta Description**, and **Focus Keyword** (from the article's SEO block) into the SEO plugin.
- [ ] Confirm focus keyword appears in: H1, first 100 words, one H2, URL, meta title, and one image alt.
- [ ] Add the **Key Takeaways** box near the top.
- [ ] Confirm the **FAQ** section is present and questions are phrased naturally (for People Also Ask).
- [ ] Add the **CTA** in intro, mid-article, and conclusion (free water test).

### B. Citations & E-E-A-T
- [ ] Verify the inline citation hyperlinks resolve (already added on key stats); add any remaining links from the Citations doc on the recommended anchor text.
- [ ] For health articles (#1, #4, #5, #10, #16, #17): apply the **"Medically reviewed by Dr. Ronald Sidney Stuart, M.D."** stamp + today's date.
- [ ] Add an author byline + bio.

### C. Schema
- [ ] Add `Article` (or `BlogPosting`) + `FAQPage`.
- [ ] Add `HowTo` on process posts (#2, #3, #8, #21, #24).
- [ ] Add `MedicalWebPage` w/ `reviewedBy` on health posts (#1, #4, #5, #10, #16, #17).
- [ ] Add `Product`/`Offer` where a system is featured (#11, #14, #23).

### D. Media & Core Web Vitals
- [ ] Add the **hero infographic** (from the design brief); export **WebP**, set the specified alt text + file name, define width/height.
- [ ] Compress images; lazy-load below-the-fold; confirm LCP image is preloaded.
- [ ] Mobile check: short paragraphs, tappable CTA buttons, click-to-call.

### E. Internal Linking
- [ ] Link to **3–6 sibling pillars** in the same cluster (see Part 4 map).
- [ ] Link to the cluster's **money page** with descriptive anchor text.
- [ ] Update **older/existing blog posts** to link up to this new pillar.
- [ ] For map posts (#6, #25): link to relevant **state/city service pages**.

### F. Publish & Promote
- [ ] Add to XML sitemap; request indexing in Search Console.
- [ ] Add a clickable **table of contents** on 3,000+ word posts.
- [ ] Share to email list + social; for #6 and #25, add an **embed/share snippet** to earn backlinks.
- [ ] Log publish date + target keyword in the tracking sheet.

## PART 5 — KPIs & REVIEW CADENCE

**Track per article (in Search Console + GA4):**
- Impressions & average position for the focus keyword (and secondary keywords).
- Clicks / organic sessions.
- Featured snippet / People-Also-Found / AI Overview appearances.
- Engagement: scroll depth, time on page.
- **Conversions:** free-water-test form submits and calls attributed to the post.

**Review schedule:**
- **30 days post-publish:** confirm indexing, check initial rankings, fix any technical issues.
- **90 days:** assess ranking trajectory; add internal links from newer posts; expand thin sections if stuck on page 2.
- **Every 6–12 months:** refresh stats and "Last updated" date; re-confirm citations; update the medical-review date on health posts.

**Quick wins to watch for:**
- Posts ranking positions 5–15 → add internal links + tighten the intro answer to push onto page 1.
- Posts earning impressions but few clicks → rewrite the meta title/description for click-through.
- High-traffic posts → add or strengthen the in-content lead form.
